Import / Export measurements

Import: paste the contents of a log_digitizer_import_*.json file (from a capture script, or exported below) then click Load. This overwrites the table and updates the section/angle counts to match. "spacing" is now a per-gap array (one entry shorter than the number of sections) — a single legacy number is still accepted and applied uniformly to every gap.
Export: save whatever's currently in the table below as a log_digitizer_import_*.json file — same format the Fusion spline-sketch script reads, so manually-entered data works with it too, not just the capture scripts. Note: if your capture/Fusion scripts assume a single uniform spacing number, they'll need updating to read the new per-gap array.

Using this in Fusion 360: the simplest path is the combined 3D reference file below — import it as a 3D sketch, apply the mirror step described next, then Loft across all the profiles directly from that one sketch. The per-section files above (create 4 offset planes along your loft axis at Y = 0, 150, 300, 450 mm, insert one section DXF per plane) are the alternative if you'd rather work plane-by-plane instead. For a single-face smooth loft instead of a faceted one, use the separate Fusion spline-sketch script rather than these DXF exports.

Orientation: the 0° reading (first laser measurement, before any rotation) is exported straight up the sketch's local +Y axis, matching the physical "top of log" position. After importing the 3D reference sketch, apply Modify → Mirror across the origin XY plane once — this has been confirmed to correct the orientation reliably. Do this every time as a standard step; it's a single consistent correction, not something to chase out of the export file.

If you've had to mirror the finished loft body through the XY plane to make it look right: that's a sign your planes' local Y is mapping to global −Z instead of +Z, flipping "top of log" to "bottom of log" on import. The digitizer's vertical (Z) orientation is currently fixed to the un-flipped convention, so continue applying the Modify → Mirror step above each time rather than looking for a toggle here.

Verifying orientation after import: Fusion's DXF importer silently drops TEXT and POINT entities (it only keeps solids/curves/surfaces/meshes) — so instead of text labels, each section DXF marks every point with a small circle, sized to grow from smallest (0°) to largest around the sequence, plus a radial line pointing straight at the 0° point with a double-ringed circle marking it specifically. After inserting a sketch, find the double-ring circle — that's your C=0 reference — and check that the radial line points the same real-world direction (relative to your known headstock/tailstock/up reference) on every section. These markers sit on their own layers (C0_MARK, ANGLE_MARK) so you can hide them once orientation's confirmed, without touching the profile geometry itself.
